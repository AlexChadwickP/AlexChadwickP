## ⭐ Featured Project

### [create-ac-app](https://github.com/AlexChadwickP/create-ac-app)

A production-ready full-stack application template built from real-world experience. This monorepo starter provides everything you need to build modern web applications with end-to-end type safety.

**Tech Stack:**
- **Backend:** Hono + tRPC + Drizzle ORM + better-auth
- **Frontend:** React + Vite + TanStack Router + TanStack Query
- **Database:** PostgreSQL + Redis
- **Dev Environment:** Docker Compose with MailHog and Azurite

**Key Features:**
- Complete type safety from database to frontend
- File-based routing with automatic route generation
- Built-in authentication and session management
- Containerized development environment
- Database migrations and schema management

Built with experience from production deployments at The Fusion Works.
